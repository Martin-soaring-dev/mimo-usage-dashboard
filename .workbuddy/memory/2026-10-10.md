## MiMo Desktop 插件接口调研

- 产出 `docs/plugin-interface.md`（完整版接口清单）。
- 关键结论：
  - 插件 SDK 是 `@mimo-ai/plugin@0.1.15`（+ `@mimo-ai/sdk`），入口 `.`/`./tool`/`./tui`；
    hooks 全是服务端能力（tool/config/chat.*/session.*/actor.*/auth/provider），**无 UI 注册接口**。
  - 插件通过配置 `plugin` 数组加载，spec 支持：npm 包名 / `github:owner/repo` / tarball URL / `file://` 绝对路径。
    归一化见 app.asar `out/main/node.mjs` L730572；加载 L610702（`PluginLoader.loadExternal`）；
    spec 解析 L254075-254532（`isPathPluginSpec` → npm 走 `npm.add`）。
  - 入口解析优先 `package.json` 的 `exports["./server"]`，否则回退 `main`。本项目缺 `"./server"`，走的是 main 回退。
  - 另有文件 hook 扫描：`{hook,hooks}/*.{js,ts}`（`FILE_HOOK_GLOB`，node.mjs L610551），用 Bun.build 编译后 import。
  - 桌面内置工具（image_gen/tts/automation/contacts 等）通过 `globalThis.__mimo*` 桥暴露，
    定义在 `out/main/desktop-tools-plugin.mjs`；插件是否可见未运行时验证。
  - README 所称 `{plugin,plugins}/*.{ts,js}` 目录扫描**未在 App 打包产物中直接读到**，以 `plugin` 数组为准。

## 抽取 app.asar 内文件的方法（重要）

- `require('@electron/asar').listPackage(path)` 返回**反斜杠**路径（`\out\main\x.mjs`）；
  `extractFile` 对补丁过的包会失败。
- 可行做法：`getRawHeader(asar)` 拿 `{header, headerSize}`；数据区起点 = `8 + headerSize`；
  按 header 里条目的 `offset`/`size` 直接从 `fs.readFileSync(asar)` 切片。
- 本机 asar 路径：`D:/Program Files/Xiaomi MiMo/resources/app.asar`（另一个 `.mimo-usage-backup` 是补丁备份）。
- 引擎打包产物是 `out/main/node.mjs`（约 37MB，含完整开源引擎）。

- **命令注册机制（关键）**：引擎 `Command.state` 把每个**技能名**注册成同名斜杠命令
  （`for (item of skill.all()) commands3[item.name] = {source:"skill", template: item.content}`）。
  所以「目录名/`name` = `usage` 的技能」→ 自动获得 `/usage`；自定义命令/MCP 可覆盖内置命令，**技能不能覆盖已有命令**。
  命令来源四类：内置 / 配置 `command` 字段 / MCP prompts / 技能。
- **sci-widget 渲染契约（关键约束）**：桌面 `MarkdownImpl` 里 `xn="sci-widget"`，
  用 `<iframe sandbox="allow-scripts" srcDoc=wrap(html)>` 承载，强制注入 CSP：
  `default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:; font-src data:; connect-src 'none'`。
  高度 80–560px（`k=80, G=560, gn=0.7`），自动上报脚本 postMessage `sci-widget:height`。
  **`connect-src 'none'` ⇒ 卡片内不能 fetch/XHR ⇒ 数据必须内联**（`renderCard` 把 JSON 塞进 `var DATA`）。
- **上下文上限来源**：DB 不存。`sessionContext()` 占用取最新 `step-finish` 的 `tokens.total`；
  上限优先 `opts.limit`，否则查内置表 `MODEL_CONTEXT_LIMITS`（从引擎 bundle 抄录：
  `mimo-v2.6-pro/flash`=1048576、`mimo-v2-flash`=262144、`glm-5.3`=1000000 等）。
  实测本机 `mimo-v2.6-flash` 占用 ~63万、占比 ~60%。

## 21:30-22:00 · /usage 重构：按内容量分流（侧栏 URL + 内联卡片）

**用户诉求**：总用量/ Session 用量 → 侧边弹窗；上下文用量 → 内联卡片。
核心痛点是"卡片 HTML 还要 AI 逐字输出"，既耗 token 又会出现「正在生成交互演示…」的流式等待。

**关键发现（从 app.asar 实证）**：
- `MarkdownImpl` 里 sci-widget 的渲染是 `isSciWidget(lang) ? (streaming ? <Loading/> : <Iframe/>)`；
  「正在生成交互演示…」= `sciWidget.generating`，只在 **streaming=true** 时显示，流结束即换真卡片。
  → 所以"卡住"不是卡片 bug，是流未闭合。根治办法就是**别让 AI 输出 HTML**。
- `present_files` 官方明确 **禁止用于 HTML**（"Do not open HTML files with present_files"），
  且默认会**修改本地文件**加 AI 标记 → 不是弹实时卡片的正确工具，产物路线放弃。
- `@mimo-ai/plugin` 无原生弹窗能力，所以多选 UI 改为**面板页内的 tab 切换**。

**改动**：
- `card-render.mjs`：新增 `renderPanel(data,{refreshMs,apiBase})` —— 侧边面板整页（`body.panel` 窄栏：
  grid4→2×2、表格 `col-hide` 隐藏更新列、sticky 标题栏 + 刷新按钮、`?refresh=N` 自动刷新）。
  新增 `.panel` 相关 CSS。
- `server.mjs`：新增 `/panel`（`kind=token|session|context`，支持 `days`/`refresh`/`session`/`limit`）。
- `plugin/usage-dashboard.mjs`：`usage_card` 按 `KIND_MODE` 分发 ——
  `token`/`session` → 确保服务在跑并返回 **`/panel?kind=…` 一行链接**；
  `context` → 内联 sci-widget 卡片；`all` → 链接 + 内联。新增 `panelUrl()` 与 `refresh` 参数。
- `skill/usage/SKILL.md`：更新参数映射与"两种模式"输出要求。
- 测试：`test/smoke.mjs` 改为断言分发模式；`test/plugin-e2e.mjs` 重写为 32 项断言（全绿）。
